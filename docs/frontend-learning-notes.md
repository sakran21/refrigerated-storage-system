# Frontend Learning Notes

## Current frontend goal

Before continuing React development, the goal is to build enough frontend literacy to understand the files being edited instead of blindly copying code.

## Minimum skills needed for this project

- HTML: page structure, forms, buttons, inputs
- CSS: selectors, spacing, flexbox, basic layout
- JavaScript: variables, functions, arrays, objects, events, fetch
- TypeScript: basic type annotations while working inside React
- React: components, props, state, effects, lists, forms, API calls
